# Bible 57 Privacy Policy

This is a standalone static site for hosting the Bible 57 privacy policy on Vercel. It includes English and Kiswahili versions and uses the Bible icon supplied by the app.

## Deploy to Vercel

1. Push this project to the Git repository you want Vercel to deploy.
2. In Vercel, import that repository.
3. Set **Root Directory** to `privacy-policy`.
4. Choose **Other** as the framework preset. No build command or output directory is needed; Vercel serves `index.html` directly.
5. Deploy. The policy will be available at the project's root URL.

Before publishing, add a real developer privacy/support contact to the policy and confirm that the listed backend providers, retention behavior, and enabled services still match production. The app currently has no account system or cloud backup, so the policy does not describe those as available features.
